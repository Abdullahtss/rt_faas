Unsupervised: it learned only what genuine payments look like and never saw a fraud label, so it can flag new kinds of fraud nobody has labelled yet. Because it is noisier, it can send a payment to the review queue (Medium) but never raises a High alert on its own.

    


    

      
Data drift · live inputs vs training days (PSI)

      

      
Population Stability Index compares how each input is distributed live against the training days, using training deciles as bins. Below 0.1 is stable, 0.1–0.25 is worth watching, and above 0.25 means live traffic no longer looks like the training data, so the model should be retrained.
