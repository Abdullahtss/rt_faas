The live console replays `bs140513_032310.csv`, the public BankSim dataset
(Lopez-Rojas and Axelsson, 2014). It is synthetic card-payment data calibrated
on a Spanish bank. It is not copied into git because the file is about 48 MB.

If `data/bs140513_032310.csv` is missing, download it from:

https://raw.githubusercontent.com/0xSushmitha/Fraud-detection-in-financial-Transactions/main/data/bs140513_032310.csv

The original Kaggle release is https://www.kaggle.com/datasets/ealaxi/banksim1
